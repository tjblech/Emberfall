# Emberfall Tactical Overhaul

## Replaced
- Old tap-to-attack / flat upgrade / +5% prestige loop.
- Glossy rounded-card visual treatment and emoji enemy presentation.

## Added
- Shaped 5x5 backpack inventory with rotation and manual placement.
- Item effects based on adjacency, empty neighboring cells, bag edge, shared rows, and loose-gear state.
- Automatic weapon combat plus a manual Focus ability.
- Common, Rare, Cursed, and Relic gear with mechanic-changing effects.
- Loot choices after milestone fights, Elites, bosses, traders, shrines, hunts, cursed vaults, and an unlockable blacksmith.
- Boss rewards that alter bag dimensions, pouch capacity, or harness toughness.
- Essence meta-progression that unlocks new systems/item pools instead of flat prestige percentages.
- Wanderer and unlockable Scavenger starting styles.
- Codex and persistent run records.
- Export Save / Import Save preserved in the new version.
- Basic migration from the original Emberfall local save into Essence without deleting the old save.

## Style
- Dark tactical palette: charcoal, aged brass, warm parchment text, thin hard-edged panels, restrained effects, and no glossy neon gradients.
